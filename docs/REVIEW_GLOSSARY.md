# Review 用語集（QA / テスト体系寄せ）

画面・デモ手順・スプリント文書の **ユーザー向け文言** はこの表に揃える。  
内部型名（`Observation`, `SourceSpan`, `bindingChange` 等）はコード識別子として残してよい。

| 概念 | 統一語（UI） | 使わない語 | 備考 |
|------|-------------|------------|------|
| 左カラムの単位 | **検査意図** | 項目（単独）、Span、Source（UI） | 製品固有語。進捗も「N 件の検査意図」 |
| 左カラム名 | **検査意図** | 検査したかったこと | 単位名と一致させる |
| 中央カラム名 | **実行手順** | 実際に行った操作、Plan（UI） | 手順＝実行された操作列 |
| 右カラム名 | **証跡** | 証拠、Observation（UI）、画面状態 | QA の Evidence。生データは内部で Observation |
| 対応なし | **未マッピング** | 欠落、欠損、Plan に落ちていない（見出し） | PRODUCT_DIRECTION の Mapping Coverage |
| レビュー状態 | **未レビュー / レビュー中 / レビュー済** | 未確認 / 確認中 / 確認済み | 人間のレビュー進捗 |
| レビュー判定 | **適合 / 不適合 / 保留** | 意図どおり / 要修正 / 判断保留 | レビュー合否 |
| シナリオ完了 | **レビュー完了**（状態: 未完了 / 完了） | レビュー済み（判定と混同） | 全検査意図の判定後 |
| 実行の合否 | **合格 / 不合格** | passed（UI）、成功（実行結果） | 機械判定。操作行も同じ |
| 未実施の手順 | **未実行** | skipped（UI） | |
| 警告の総称 | **要確認** | 注意シグナル、レビューシグナル | ヘッダ枠 |
| Binding の差 | **Binding差分** | Binding 変更（UI では差分に寄せる） | 要確認の内訳 |
| Expected / Actual | **期待値 / 実績値** | Expected/Actual のみ（併記可） | Assertion 表示 |

## 表示例

- 実行結果: **合格**
- レビュー進捗: **1 / 4 件レビュー済**
- レビュー判定: **未完了** → 完了操作後 **完了**
- 要確認: **Binding差分 5 · 未マッピング（意図）1 · 未マッピング（手順）1 · 未実行 1**
